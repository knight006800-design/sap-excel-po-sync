# 웅이전용 — SAP–엑셀 구매오더 수량 비교

## 사용
1. 엑셀 연결
2. SAP 자재코드 / 오더수량 각각 Ctrl+V
3. **비교·결과 생성**
4. **결과 수량** 전체 복사 → SAP 오더수량 열에 Ctrl+V

- 엑셀에 있는 코드 → 엑셀 수량
- 엑셀에 없는 코드 → SAP 원래 수량 유지 (순서 그대로)
- 엑셀에만 있는 코드 → 지정 파일로 추출 (원본 미수정)

좌표 자동 기입 없음.
