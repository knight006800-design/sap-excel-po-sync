# 웅이전용 — SAP–엑셀 구매오더 수량 동기화

## 사용
1. **엑셀 연결** — 구매오더 엑셀 선택
2. **행/수량 초기설정** — 첫 행 Y / 행높이 / 수량 X 클릭지정 후 저장
3. SAP에서 자재번호 열 **Ctrl+C** → 프로그램 붙여넣기 칸에 **Ctrl+V**
4. **동기화 실행**
   - 매칭: SAP 오더수량을 엑셀 D열 값으로 수정
   - 미매칭: 동일 양식(1행 서식) 새 엑셀로 행 이동 (음영 없음)

OCR은 사용하지 않습니다. 붙여넣기 순서가 SAP 화면 행 순서와 같아야 합니다.
