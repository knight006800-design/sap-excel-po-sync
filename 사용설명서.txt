웅이전용 — SAP–엑셀 구매오더 수량 비교
=====================================

사용 순서
1. 엑셀 파일 연결
2. (선택) 엑셀 미매칭 저장 폴더·파일명 지정
3. SAP 자재번호 열 → ① SAP 자재코드 칸에 Ctrl+V
4. SAP 오더수량 열 → ② SAP 오더수량 칸에 Ctrl+V
5. [비교·결과 생성]
6. ③ 결과 수량을 드래그(또는 전체선택) → Ctrl+C → SAP 오더수량 열에 Ctrl+V

결과 규칙 (SAP 행 순서 그대로)
- 엑셀에 있는 코드 → 엑셀 수량으로 기입 (상태: 수정/동일)
- 엑셀에 없는 코드 → SAP 원래 수량 유지 (상태: 유지)
- 엑셀에만 있는 코드 → 지정 파일로 복사 추출 (원본 엑셀 수정 없음)

주의
- 좌표 클릭·자동 기입은 없습니다.
- 결과 칸만 SAP에 붙여넣으면 됩니다.
