웅이전용 — SAP–엑셀 구매오더 수량 동기화
=====================================

다른 PC에서
- woongyi-windows.zip 압축 해제
- 웅이전용.exe 실행 (폴더 안에 넣지 않아도 됨)
- Excel이 설치된 Windows PC 필요

사용 순서
1. 엑셀 파일 연결
2. [행/수량 초기설정] — 첫 행 Y, 행 높이, 수량 칸 X 클릭지정 후 저장
3. SAP에서 자재번호 열 복사 → 「SAP 자재코드」칸에 Ctrl+V
4. SAP에서 오더수량 열 복사 → 「SAP 오더수량」칸에 Ctrl+V
   (코드와 같은 위→아래 순서)
5. [동기화 실행]
   - 비교: 엑셀 B열 코드 ↔ 붙여넣은 SAP 코드
   - 수량 다름 → SAP 오더수량을 엑셀 D열 값으로 자동 수정
   - 수량 같음 → 스킵
   - 미매칭 엑셀 행 → 동일 양식(1행 서식) 새 엑셀로 자동 추출

주의
- OCR 없음
- 실행 중 마우스 금지, ESC=중지
- 로그: 구동점검 폴더
