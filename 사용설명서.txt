웅이전용 — SAP–엑셀 구매오더 수량 비교
=====================================

사용 순서
1. 엑셀 파일 연결
2. (선택) SAP에 없는 엑셀 코드 추출 폴더·파일명 지정
3. SAP 자재번호 열 → ① SAP 자재코드 칸에 Ctrl+V
4. [비교·결과 생성]
5. 오류가 없으면 ② 결과 수량 전체 복사 → SAP 오더수량 열에 Ctrl+V

규칙
1) SAP 자재코드와 동일한 엑셀 코드의 오더수량을 가져온다
2) SAP에는 있으나 엑셀에 없는 코드
   → 「엑셀 코드기입 오류/휴먼에러」로 안내
   → 75% 이상 유사한 엑셀 코드가 있으면 제안
   → 엑셀 수정 후 재작업
3) SAP에 없는 엑셀 코드 → 지정 파일로 따로 추출 (원본 엑셀 미수정)
   → 파일명 기본값: 실행일 `20260730_` (뒤에 원하는 이름 추가 가능)

주의
- SAP 오더수량 붙여넣기 칸 없음 (엑셀에서만 수량 가져옴)
- 좌표 자동 기입 없음
